# ルールのテストの対象外の一覧

[ルールとテストの結果のページ](test-report.md)で、テストで確かめる性質でない節を「対象外」と宣言する一覧。仕様のページ（`docs/cartagraph/`）にはテストの話を書かず、ここに1か所で置く。

- **ページ**：ルールのページのファイル名（`.md` なし。例：`check`）
- **節**：見出しの文字そのまま。空にすると、そのページ全体が対象外
- **理由**：なぜテストで確かめないかを1行で（`|` は書けない）

どの節を載せるか、対象外の節にタグを付けたとき・見出しを直したときに何が止まるかは、[テストのルール](../process/rules/testing.md)の「ルールのテストのタグ」が正。

| ページ | 節 | 理由 |
|---|---|---|
| index | | 構想の概観。振る舞いを決めておらず、確かめるルールが無い |
| balance | | 数値の目安（相場観）の説明で、守る判定が無い。値そのものは `rules/` と各テストが持つ |
| character-growth | この章の設計原則 | 設計の方針の説明で、テストで確かめる振る舞いが無い |
| comparison-and-titles | この章の設計原則 | 設計の方針の説明で、テストで確かめる振る舞いが無い |
| card-face-back | 設計原則 | 設計の方針の説明で、テストで確かめる振る舞いが無い |
