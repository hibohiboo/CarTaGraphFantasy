# 未解決論点トラッカー

カルタグラフの設計で、まだ決まっていない論点だけを管理する。grillingによる深掘りは、この一覧から優先順位をつけて進める。

決着したら、決まったことを該当する仕様のページへ、決めた理由・経緯を[デザイナーノート](notes/index.md)へ書き、ここからは消す。これまでに決着した論点の一覧は[デザイナーノート](notes/index.md#決着した論点)にある。

## 次に詰める候補

- **シーンカードの「目的」「終了条件」という属性** — 閲覧サイトのセッション試作（シーン構築・シーン進行画面）を作る中で出てきた案。[選択肢カード＝イベントカード](cartagraph/play-and-field.md#カードをプレイした結果として何が変化するのか)は「発火条件・効果・GM向け補足」の3要素構造と決着しているが、シーン単位で「目的」「終了条件」を持たせるかどうかは未検討。持たせる場合、既存の3要素構造や[終了条件（セッションの終了条件）](cartagraph/party-and-session.md#非同期セッションの進行)と役割が重複しないかも要確認。2026-09-23、ノード間の移動は選択肢カードの効果[「次のシーンへ進む」](cartagraph/play-and-field.md#次のシーンへ進む)として決着したが、シーン側の終了条件による遷移は引き続き未検討。アプリの型にある仮フィールド（`DeckNode.objective`・`endCondition`）と、選択肢カードの遷移先（`CardDef.nextNodeId`）の関係もあわせて整理する。2026-09-27、GM不在のソロでは「依頼を解決した」ことをシーンの属性ではなく[達成カード](cartagraph/solo-village.md#達成カード)（仮ルール）で表しており、この論点には踏み込んでいない。
- **自動戦闘（仮ルール）の正式化** — GM不在のソロプレイ向けに、[自動戦闘（仮ルール）](cartagraph/auto-combat.md)を導入した（2026-09-23）。優先順位リスト、ラウンド上限、敗北時の再挑戦と「再挑戦の記憶」、軽量モードでのカウント制の自動実行、ソロ開始時の初期装備（2026-09-27 以降は村スタートのシナリオでは使わず、テスト専用のシナリオだけが使う）を、プレイテストを経て正式なルールにするかどうかは未検討。
- **GM不在のソロの進行（仮ルール）の正式化** — 村スタートのシナリオの村パートのため、[GM不在のソロの進行（仮ルール）](cartagraph/solo-village.md)を導入した（2026-09-27）。達成カード、選択肢カードの配る条件・使える条件（ハードロック）、能力値の上がり方（各1から始めて1件で＋1、上限5）、HP・＜行動値＞の付与、引換カードとお店、セッション中の即時反映、シーンに入ったときの描写（遷移カードの説明文）と結末タグの即時反映（2026-09-27 追加）を、プレイテストを経て正式なルールにするか、GM不在でないセッションでも目安として使うかは未検討。2026-10-04、適用範囲がソロ開始だけでなく[GM不在の募集](cartagraph/scenario-flow.md#募集とセッション)から始めたセッション（提案を裁定する人間のGMがいる）にも広がった。
- **無反応による中断の再開** — 2026-10-04、[中断](cartagraph/party-and-session.md#非同期セッションの進行)を終了条件から外し、再開できる一時停止とした。提案の裁定待ちによる中断はドライバーが再開すると決めたが、一定期間反応が無いことによる中断を、いつ・誰が（ドライバー、ナビゲーター、GM）再開できるかは未検討。無反応の中断そのものも未実装。
- **カウント制の1ラウンドの行動回数と数値バランスの両立** — [数値バランスの相場観](cartagraph/balance.md)の「基本攻撃でHPの2〜3割」と「3〜5ラウンドで決着」は、カウント制で1ラウンドに何回行動できるか（行動値とコストの比）が決まらないと同時に満たせない。例えば行動値10〜12・コスト3では1ラウンドに3〜4回行動でき、1〜2ラウンドで決着してしまう。自動戦闘の検討（2026-09-23）で判明した。
- **キャラクター作成時の体・技・心の初期配分方法** — [探索者向けの判定ルール](cartagraph/exploration-check.md)は能力値の使い道（2d6との組み合わせ）は決着しているが、キャラメイク時にどう割り振るか（ポイント制／固定配分／CPとの連動の有無など）は[キャラクターの成長とキャラメイク（CP制）](cartagraph/character-growth.md)にも記載がなく未検討。作成時の HP（アプリでは仮に、能力値を持って作ったときだけ一定の値を持たせている）も、あわせて決める。GM不在のソロでは仮に[各1から始めて依頼ごとに＋1](cartagraph/solo-village.md#能力値の上がり方)としているが、この論点の決着ではない。
