# シナリオタイプ

シナリオが、遊びの中でどの仕組みを使うかを表す目印を整理する。

## PCはすべて冒険者

PCに典型的な役割の区切りは設けない。どのPCも[冒険者](../glossary.md#冒険者)であり、作成したときから能力値（体・技・心）・HP・基本＜行動値＞を持つ（[キャラクターの成長とキャラメイク（CP制）](character-growth.md#pcが持つデータ)）。

## タイプの宣言

既定のタイプは**冒険**で、[判定](check.md)も[戦闘](combat.md)もありうる。シナリオは、使わない仕組みだけを宣言する。

| 宣言 | 意味 |
|---|---|
| （なし） | 冒険。判定も戦闘もありうる |
| 戦闘なし | 戦闘を使わない |
| 判定なし | 判定を使わない |
| 戦闘なし・判定なし | **読み物**と呼ぶ。選択肢を選ぶだけで進む |

「戦闘なし」と宣言したシナリオに、戦闘のシーンを置いてはならない。[空間モデル](scenario-flow.md#シナリオのメタデータ)も持たない。

## タイプは目印である

- タイプは、GM・PLがシナリオを選ぶときの目印である。PCの参加資格にはしない
- どのシナリオにも、PCのキャラクターデッキ全体を[セッションスナップショット](graph.md#セッションスナップショットとマージ)として持ち込む。シナリオが使わないカード（「戦闘なし」のシナリオでの戦闘スキルなど）も持ち込み、使うかどうかはシナリオ次第とする
- 参加の前提は、タイプではなく[前提スキル／推奨知識のタグ](unlock.md#プレイ参加側のゲーム内アンロック)で示す
