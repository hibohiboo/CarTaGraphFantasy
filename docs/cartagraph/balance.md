# 数値バランスの相場観

HP・ダメージ量・カードコスト・目標値・CPなど、[戦闘ルール](combat.md)・[判定ルール](check.md)・[キャラクターの成長とキャラメイク（CP制）](character-growth.md)にまたがる数値の目安を一箇所にまとめる。

## スコープ

「HP=20」「ダメージ=1d6+2」のような厳密な数値表はここでは決めない。「1回の攻撃でHPの何割減るか」のような**比率・相場観としての設計方針**だけを定め、具体的な数値は実装・プレイテストのフェーズで調整する。

## 戦闘の体験ターゲット

1回の戦闘（濃密モード）は**3〜5ラウンド程度**で決着することを目安にする。

## 探索判定の難易度カーブ

[体・技・心＋2d6 vs 目標値](check.md#判定の基本メカニズム)の判定は、未熟なPC（能力値が低い）でも五分五分〜やや不利程度で成功し、熟練したPC（能力値が高い）ほど安定して成功する、滑らかなカーブにする。極端に低い成功率にはしない。

## 基準となる数値の桁感

[戦闘ルールの記述例](combat.md#行動値の動的な減少とマイナスの持ち越し)（行動値の例：A=13、B=10、コスト5）に合わせて、次の桁感で揃える。

- **行動値・HP** — 十〜二十程度の二桁
- **カードコスト** — 一桁（1〜7程度）
- **能力値（体・技・心）** — 1〜5程度の小さい数値
- **目標値** — 7〜9あたりを標準難易度の目安とする（2d6＋能力値との組み合わせで、前節の難易度カーブに対応）

## HP・ダメージ・カードコストの関係

基本的な攻撃1回で、相手のHPの**2〜3割程度**を削る想定とする（平均的なコストのカードを基準にする）。コストが高いカードほどダメージも比例して大きくなる。高コストのカードはより大きな割合を削れ、低コストのカードは複数回撃てる代わりに1回あたりの削り量は小さい。

## CPの桁感

- 1セッションクリアで得られる[基本CP](character-growth.md#cp付与の構造)は、カード数枚分（2〜4枚程度）と交換できる量を目安とする。
- 新規キャラメイク時の初期CPは、冒険者の基本装備一式が揃う程度を想定する。
- カード1枚のCPコストは、[強いカードほど高コストという相対的な指針](character-growth.md#cp予算はハードな制約)にとどめ、機械的な自動算出はしない。

## この章の設計原則

1. 厳密な数値表ではなく、比率・相場観としての設計方針を定める。具体的な数値は実装・プレイテストのフェーズで調整する。
2. 「体験のターゲット（何ラウンドで決着するか、判定の難易度感）」から逆算して数値の桁感・比率を決める。
3. 行動値・HP・カードコスト・能力値・目標値・CPの桁感を横断的に揃え、システム全体で数値の感覚がちぐはぐにならないようにする。
4. カード1枚1枚のコストは機械的な計算式で自動算出せず、相対的な指針としてシステム製作者の裁定に委ねる。
