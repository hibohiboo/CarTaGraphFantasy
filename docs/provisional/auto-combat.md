# 自動戦闘

GM不在のソロプレイ向けに、[自動戦闘（仮ルール）](../cartagraph/auto-combat.md)を導入した（2026-09-23）。プレイテスト前の仮ルールで、正式なルールにするかどうかは決めていない。

- **何が仮か** — 優先順位リスト、ラウンド上限、敗北時の再挑戦と「再挑戦の記憶」、軽量モードでのカウント制の自動実行、ソロ開始時の初期装備（2026-09-27 以降は村スタートのシナリオでは使わず、テスト専用のシナリオだけが使う）
- **数値の参考** — [自動戦闘のシミュレーション結果](../cartagraph/auto-combat-simulation.md)
- **関係する論点** — [未解決論点](../open-questions.md)「カウント制の1ラウンドの行動回数と数値バランスの両立」

2026-10-10、[未解決論点](../open-questions.md)の「自動戦闘（仮ルール）の正式化」をここへ移した。
