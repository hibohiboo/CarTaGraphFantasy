# キャラクター作成の能力値の配分と HP・行動値

[キャラクターの成長とキャラメイク（CP制）](../cartagraph/character-growth.md#pcが持つデータ)は「PC は作成したときから能力値・HP・基本＜行動値＞を持つ」と決めているが、能力値をどう割り振るか、HP・基本＜行動値＞をいくつにするかは決めていない。[判定ルール](../cartagraph/check.md)は能力値の使い道（2d6との組み合わせ）だけを決めている。仕様ページには仮の値を書いていない（アプリだけが仮の値で動く）。

- **アプリの仮ルール** — 合計を範囲内で配分し、どの PC にも一定の HP（20）・基本＜行動値＞（10）を持たせる。値は `rules/character-creation.json`（[Webアプリの仕組み「ルールの JSON」](../architecture/web-app.md#ルールの-json)）。HP・基本＜行動値＞の値は、村はずれの一歩の成長で与えていた値と同じにした（試験官との戦いの前提を変えないため。プラン `docs/plans/2026-10-10-冒険者だけにする.md` の E5）。キャラクター作成の画面にも「仮ルール」と表示している
- **ソロ開始の能力値** — 名前だけで始めるソロ開始（村はずれの一歩など）の PC は、合計を体・技・心に均等に配る（いまの値で各3。同じプランの F2）。村はずれの一歩の開始画面にも「仮ルール」と表示している
- **関係する仮ルール** — [GM不在のソロの進行](solo-village.md)の「依頼ごとに＋1、上限あり」は、この配分の決着ではない。旅立ちの酒場は、合計をそろえた固定のプリセットで配る（チュートリアル固有の仮ルール）

2026-10-10、[未解決論点](../open-questions.md)の「キャラクター作成時の体・技・心の初期配分方法」をここへ移した。同じ日に、PC を役割で区切るのをやめ、どの PC も作成したときから HP・基本＜行動値＞を持つようにしたことに合わせ、基本＜行動値＞を含めた（[冒険者だけにする](../backlog/adventurer-only.md)）。
