# キャラクター作成の能力値の配分と HP

[探索者向けの判定ルール](../cartagraph/exploration-check.md)は能力値の使い道（2d6との組み合わせ）は決着しているが、キャラメイク時にどう割り振るかは[キャラクターの成長とキャラメイク（CP制）](../cartagraph/character-growth.md)にも記載がなく、決めていない。作成時の HP も決めていない。仕様ページには仮ルールを書いていない（アプリだけが仮の値で動く）。

- **アプリの仮ルール** — 合計を範囲内で配分し、能力値を持って作ったときだけ一定の HP を持たせる。値は `rules/character-creation.json`（[Webアプリの仕組み「ルールの JSON」](../architecture/web-app.md#ルールの-json)）。キャラクター作成の画面にも「仮ルール」と表示している
- **関係する仮ルール** — [GM不在のソロの進行](solo-village.md)では仮に「各1から始めて依頼ごとに＋1」としているが、この配分の決着ではない。旅立ちの酒場は、合計をそろえた固定のプリセットで配る（チュートリアル固有の仮ルール）
