# GM不在のソロの進行

村スタートのシナリオの村パートのため、[GM不在のソロの進行（仮ルール）](../cartagraph/solo-village.md)を導入した（2026-09-27）。人間のGMなら裁量で行うことを、カードに書いた条件と効果で機械的に行う仮ルール。

- **何が仮か** — 達成カード、選択肢カードの配る条件・使える条件（ハードロック）、能力値の上がり方（1件で＋1、上限5）、引換カードとお店、セッション中の即時反映、シーンに入ったときの描写（遷移カードの説明文）と結末タグの即時反映（2026-09-27 追加）
- **適用範囲** — 2026-10-04、ソロ開始だけでなく[GM不在の募集](../cartagraph/scenario-flow.md#募集とセッション)から始めたセッション（提案を裁定する人間のGMがいる）にも広がった
- **関係する仮ルール** — 能力値の上がり方は、[キャラクター作成の能力値の配分と HP・行動値](character-creation.md)を決着させない

2026-10-10、[未解決論点](../open-questions.md)の「GM不在のソロの進行（仮ルール）の正式化」をここへ移した。
