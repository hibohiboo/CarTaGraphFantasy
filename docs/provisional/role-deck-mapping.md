# ロールごとのデッキ構成

[PCのロールとシナリオタイプ](../cartagraph/role-and-scenario.md)の「ロールごとのデッキ構成（仮マッピング）」。典型ロール（旅人・探索者・冒険者）が持つデータと、シナリオの性質（ビジュアルノベル的／ゲームブック的／TRPG的）の対応を、仮に置いている。

- **アプリでの使われ方** — 典型ロールは、PC が持つデータ（能力値・戦闘スキルカード）から導く（`packages/domain/src/character/archetype.ts`）

2026-10-10、仮ルールの一覧を作るときに、仕様ページの「仮マッピング」の印から登録した。
