# シーンの「目的」「終了条件」

閲覧サイトのセッション試作（シーン構築・シーン進行画面）を作る中で出てきた案。[選択肢カード＝イベントカード](../cartagraph/play-and-field.md#カードをプレイした結果として何が変化するのか)は「発火条件・効果・GM向け補足」の3要素構造と決着しているが、シーン単位で「目的」「終了条件」を持たせるかどうかは決めていない。仕様ページには仮ルールを書いていない（アプリだけが仮の項目を持つ）。

- **アプリの仮ルール** — シーン編集の画面に「目的」「終了条件」の欄があり（ドメインの型の `DeckNode.objective`・`endCondition`）、画面に「未決の仮ルール」と表示している。書いても進行には効かない
- **決めるときに整理すること**
  - 持たせる場合、既存の3要素構造や[終了条件（セッションの終了条件）](../cartagraph/party-and-session.md#非同期セッションの進行)と役割が重複しないか
  - 2026-09-23、ノード間の移動は選択肢カードの効果[「次のシーンへ進む」](../cartagraph/play-and-field.md#次のシーンへ進む)として決着したが、シーン側の終了条件による遷移は決めていない。仮の項目と、選択肢カードの遷移先（`CardDef.nextNodeId`）の関係も整理する
  - 2026-09-27、GM不在のソロでは「依頼を解決した」ことをシーンの属性ではなく[達成カード](../cartagraph/solo-village.md#達成カード)（仮ルール）で表しており、この論点には踏み込んでいない

2026-10-10、[未解決論点](../open-questions.md)の「シーンカードの『目的』『終了条件』という属性」をここへ移した（アプリが仮の項目で動いているため）。
