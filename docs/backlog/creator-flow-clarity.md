# シナリオ製作の導線を分かりやすくする

2026-10-14、シナリオの下書きの API の C2（セッションの独立）の人間レビューで、PO が指摘した。

- シナリオ製作者（GM）は、タイトルを付け、シーンを作る、という順に進めるはずだが、シナリオ編集の画面にはメタ情報（想定人数・推奨 CP・空間モデルなど）がずっと表示されていて、ビジーに見える。導線が分かりにくい
- C2 のスコープ外なので、別の要望として置いた。画面ごとの課題（[画面ごとの課題](../screens/issues.md)）に整理してから、直し方を決める
- 2026-10-17、直し方を決めた（[プラン](https://github.com/hibohiboo/CarTaGraphFantasy/blob/main/docs/plans/2026-10-17-シナリオ製作の導線.md)）。シナリオ編集は1画面のまま、デッキ構造と結末を主役にし、メタ情報は畳んだ「公開の前に決めること」へ移す。初めて公開するまでは次にすることの案内を出し、公開の前に、公開を止める誤りと止めない注意（行き止まりのシーン・導入から届かないシーンや結末・概要が空）を出す。シーン編集はカードの配置を主役にし、前後のシーンへ移る導線を足す
