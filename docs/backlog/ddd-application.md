# ドメイン駆動設計の手順を適用する

[ロードマップ](../roadmap.md#backend-1on1) backend-1on1（データをバックエンドに置く）の下ごしらえ。2026-10-16 に文書で決めた業務領域・境界づけられたコンテキスト・集約・ユースケース（[業務領域の分類](../architecture/domain-map.md)から辿れる）の続きとして、本の残りの手順を当てはめる。

- 文書で決めるもの：イベントの流れ（イベントストーミング）、コンテキストごとの実装パターン、連携のパターンと実装、用語のコンテキスト分け、見直しのきっかけ
- コードの組み替え（`Session` の分割など、[既知の問題](../architecture/known-issues.md#ドメインモデル)）は、backend-1on1 で保存の単位を作るときに別のプランで行う
