# ルールブックを、目次から少しずつ読めるようにする

[ロードマップ](../roadmap.md) M2 の完成の条件6に当たる。課題は [画面ごとの課題「ルールブック」](../screens/issues.md#ルールブック) の RB-1 と [「遊び方」](../screens/issues.md#遊び方) の RB-2・RB-3。

- いまは読んだことを記録する操作が無く、MSW の初期データにある「遊び方」だけに「読」の印が出ている。判定ルールを読んでも印は付かない
- 「読了（自己申告）」が何のことか分からない
- 1ページの情報が多く目次も無いので、「読了」とする範囲が広すぎる
