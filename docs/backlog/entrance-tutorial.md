# 入口のチュートリアルをどちらにするか

所持キャラクターが0人のとき、ホームに2つの入口が並ぶ。

- **旅立ちの酒場**（`/pl/tutorial`）— 酒場の主人との短い問答で、能力値の傾向と旅装を選んでキャラクターを作る。GM やセッションの仕組みは使わない
- **村はずれの一歩**（`/pl/village-start`）— GM なしの1人プレイのセッションで、村の依頼・お店・冒険者試験を経て、冒険者として最初の一歩を踏み出す

入口のチュートリアルという同じ役割を2つ持つことは、[村スタート冒険者キャンペーン](village-campaign.md)の親プラン（決定事項1）が避けたかった重複である。キャンペーンは当初、酒場を置き換える予定だった。2026-09-27、人間が「どちらがよいか決めかねている」と判断を保留し、キャンペーンとは別の要望にした。

判断が出たら、片方を撤去するか統合する。

この判断待ちは、以前は既知の問題にも書いていたが、ダッシュボードで二重に出るため、2026-10-02 にこの要望ファイルへ一本化した。
