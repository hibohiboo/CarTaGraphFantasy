# トップページのダッシュボード

AI との共同開発で、進み具合や判断待ちをどんな形で見られるのがよいかを試す。これもプロダクトと同じく、使いながら形を変えていく（[体制の進化](../process/evolution.md)）。

## 1版目で決めたこと（2026-09-27）

- トップページを丸ごとダッシュボードにし、サイトの紹介は上部の小さな導入に縮める
- **情報は手で書かず、ビルド時に集める**（SSOT）。要望は `docs/backlog/` の1要望1ファイルの先頭に状態を持たせる。判断待ちは、既知の問題・未解決論点・進化ログから集める
- 過去のプランも要望として登録し、完了したものは折りたたんで見せる
- PO 向け：「決めないといけないこと」（要望の判断待ち＋未解決論点の「次に詰める候補」）を先に、その次に要望の進み具合
- 開発者向け：要望ごとのサイクルと PR、既知の問題の判断待ち、進化ログの未評価の候補
- 状態は6種類（未着手／検討中／進行中／判断待ち／完了／見送り）
- 開発サイクルを回す AI が、プランの作成時とマージ時に要望ファイルを更新する
- 試行として始め、数サイクル使ってから見直す
