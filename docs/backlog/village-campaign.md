# 村スタート冒険者キャンペーン

田舎の少年少女が冒険者を目指して旅立ち、試験を受けて冒険者になるキャンペーン。戦闘は「戦い方（カードの優先順位）を決めておけば自動で終わる」GMレスのカードゲームのように遊べる。

- 2026-09-23 に要望を受けて grilling し、4サイクル（のちに C5 を追加）に分けた
- 2026-09-27 に C5 と振り返りまで終えて完了
- 残したもの（旧チュートリアルの扱い、結末タグのカード化）は、それぞれ別の要望にした

ルールの仮決めは [自動戦闘（仮ルール）](../cartagraph/auto-combat.md) と [GM不在のソロの進行（仮ルール）](../cartagraph/solo-village.md)。
