# キャラクターに設定・容姿・画像を書けて、CP で成長できる

[ロードマップ](../roadmap.md) M2 の完成の条件4に当たる。課題は [画面ごとの課題「キャラクターシート」](../screens/issues.md#キャラクターシート) の PCS-1 と [「キャラクター作成」](../screens/issues.md#キャラクター作成) の PCN-1・PCN-2。

- いまのキャラクターシートは見るだけで、編集できない
- キャラクター作成に、設定・容姿を書く欄と、画像を設定する欄が無い
- **画像は、バックエンドができるまでブラウザの localStorage に置く**（2026-10-10、人間の判断）。シーン編集のカード画像と同じ置き方
- 成長のルールは [成長とキャラメイク（CP制）](../cartagraph/character-growth.md)
