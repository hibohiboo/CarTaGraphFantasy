# 後続シナリオの前提を、結末タグを得たシナリオまで見て判定する

- 2026-10-17、[シナリオのコピー](scenario-draft-api.md)（C3）のプランの確認の中で、人間が出した。コピーは新しいシナリオ id を持つ別のシナリオだが、題名以外は写すので、結末タグの名前も元と同じになる
- 今の仕様：結末タグのカードは、どのシナリオのどの結末で得たかと、得たときの版を持つ。再挑戦不可は、このシナリオ id で判定する。一方、後続シナリオの前提は、前提スキルのタグと同じ「タグ名の突き合わせ」で判定する（[結末タグ](../cartagraph/scenario-flow.md#連作キャンペーンの表現結末タグ)）。だから、コピー版の第1話で「第1話の成功」を得ても、第2話の前提を満たす
- 案：結末タグの前提は、タグ名に加えて、得たシナリオの id も突き合わせる。コピーは別の id なので、元のシナリオの続きの前提は満たさない
- 決めること
  - 製作者がコピーして直した第1話を、第2話から見て同じ第1話として扱いたいときの道を作るか（前提に出す元のシナリオを製作者が選べる、など）
  - 前提スキルのタグ（技能など）はシナリオに依らないので、変えるのは結末タグの前提だけにするか
  - 既存のシナリオ・保存済みの前提の移し方
- 進め方：`unlock.md`・`scenario-flow.md` の仕様と、前提を判定する仕組み・画面が変わるので、着手するときは開発サイクルのフルで回す。コピーの C3 には入れない（C3 はコピーと親の記録まで。D3 で混線を防ぐ仕組みは入れないと決めてあり、将来の拡張候補にこの要望へのリンクを足す）
