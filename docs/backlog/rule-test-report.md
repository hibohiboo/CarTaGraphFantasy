# ルールのページとテストの結果を紐づける

2026-10-19 の人間の要望。[ユースケースと E2E の結果を紐づける](usecase-e2e-report.md)に続けて、ルールのページについても、どのルールがテストで確かめられているかを見たい。

- **紐づけの単位は節**（`##` と `###` の見出し）にする（2026-10-25、人間の判断）
- **対象はルールのページ（`docs/cartagraph/`）だけ**。システムのカード一覧（`rules/cards.json`）のカードごとの紐づけは今回はしない（2026-10-25、人間の判断）

- タグを付けられるのは Vitest の3パッケージ（domain・schemas・web）。このサイクルでは `packages/domain` のテストに一通りタグを付ける（2026-10-25、人間の判断）
