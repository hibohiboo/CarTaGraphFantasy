# 軽量モード・濃密モードを「通常進行・じっくり進行」と呼ぶ

- 2026-10-16、ドメイン知識の設計の中で、人間が「濃密モードは耳慣れない言葉であまりよくない」と出した。候補（通常進行／じっくり進行、ダイジェスト／クローズアップ、通常シーン／山場、カード進行／手番進行、さくさく／じっくり）から「通常進行／じっくり進行」に決めた
- 中身が戦闘と NPC との会話の両方にまたがるので、どちらかに寄った言葉（手番・山場）より、細かさだけを表す言葉にした。「モード」をやめて「進行」にし、「非同期セッションの進行」と言葉をそろえる
- コードの識別子（`Session.mode` の `'light'`・`'dense'`、シーンの `dense`）は変えない（人間が決めた）。API とシナリオの JSON は変わらない
