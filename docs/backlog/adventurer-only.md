# 冒険者だけにする

[ロードマップ](../roadmap.md#adventurer-only) adventurer-only の完成の条件1〜5に当たる。

- 2026-10-10、人間がティザー（`docs/public/teaser/movie-v1.html`）を見て、旅人・探索者・冒険者の区切りが要らない複雑さを生んでいると判断した。旅人・探索者向けのセッションでも、冒険者の能力値やスキルは、プレイヤーがキャラクター像を固める役目を持つ
- 変える前の地点（local-flow の完了時点）に、git のタグ `before-adventurer-only` を付けた
- 画面を磨く（ui-polish）前に設計を変える。画面を磨いてから変えると、キャラクター作成・キャラクターシート・セッション選択を2度作り直すことになる
- 方針は2026-10-10に人間が決めた（プランの D1〜D4）
