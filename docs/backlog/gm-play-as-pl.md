# GM が PL を兼ねて結末まで遊ぶ

[ロードマップ](../roadmap.md#local-flow) local-flow の完成の条件4に当たる。前提は [GM が募集を出し、自分のキャラクターで応募して始める](gm-session-start.md)。

- 「GM が PL を兼ねる」とは、GM が自分のキャラクターでドライバーも務めること（[ロードマップ](../roadmap.md)「役割」）
- いまの GM の進行管理画面は、固定のサンプルのセッションを見て提案を裁定するところまで。描写を書く・選択肢を配る・シーンを進める・終える、が通しでできるかを確かめ、足りない操作を作る
