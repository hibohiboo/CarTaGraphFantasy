# セッションの募集を、冒険者の店の依頼の掲示板にする

[ロードマップ](../roadmap.md) M2 の完成の条件3に当たる。課題は [画面ごとの課題「セッション選択」](../screens/issues.md#セッション選択) の PLS-1〜7 と、[「キャラクター管理」](../screens/issues.md#キャラクター管理) の PLC-1。

- いまのセッション選択は、募集のカードごとに PC のドロップダウンと「応募する」が並び、一覧性が低い
- 「多くのPCが参加できます」「前提を満たすPCがいます」はカードの表示ではなくフィルタにする（既定は「前提を満たした依頼のみ」）
- カードに出ている「シナリオ」「GM不在」の札を外す。並んでいるのはセッションの募集で、シナリオではない
- **依頼文はシナリオに持たせる**（2026-10-10、人間の判断）。シナリオ製作者が書き、GM はセッションを始める前（募集を出すとき）に調整できる
- 借りられる PC はキャラクター管理ではなく、GM 不在のシナリオを遊ぶときにパーティを組む導線の側に置く
