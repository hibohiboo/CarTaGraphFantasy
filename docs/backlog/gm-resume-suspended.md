# セッションの中断と再開をドライバーと GM の両方からできるようにする

2026-10-10、人間の判断で、[中断](../cartagraph/party-and-session.md#非同期セッションの進行)と再開の権限を決めた（経緯は[デザイナーノート](../notes/party-and-session.md#中断を終了から一時停止に変えた経緯)）。

- **中断** — ドライバーも GM も、セッションを中断できる（いまは中断する操作が無い）
- **再開** — ドライバーも GM も、いつでも再開できる（いまはドライバーだけが、提案の裁定待ちの中断だけを再開できる）
- **裁定待ちは GM だけが解く** — 提案の裁定待ちの中断は、GM が裁定するまで再開できない（いまと同じ）
- **GM の画面で、中断中のセッションに絞る** — セッション管理（GM）の「GM として進行中」の一覧を、中断中のものだけに絞って確かめられる。中断の理由（任意の中断／提案の裁定待ち）も見える
- **無反応の中断を消す** — 反応が無い期間で自動的に中断することはやめた。GM の進行管理画面の「無反応で『中断』になるまで」の表示と、その期限（`suspendAt`）、中断の理由の「無反応」（`inactivity`）を消し、理由「任意の中断」に置き換える
- **マイルストーン** — 参加者が別の人になって反応を待つことが起きる backend-1on1 に置いた
