# GM が中断中のセッションを確かめて再開する

2026-10-10、人間の判断で、一定期間反応が無くて[中断](../cartagraph/party-and-session.md#非同期セッションの進行)したセッションは、GM がいつでも再開できると決めた（経緯は[デザイナーノート](../notes/party-and-session.md#中断を終了から一時停止に変えた経緯)）。

- **GM の画面で、中断中のセッションに絞る** — セッション管理（GM）の「GM として進行中」の一覧を、中断中のものだけに絞って確かめられる。中断の理由（無反応／提案の裁定待ち）も見える
- **無反応の中断を GM が再開する** — 待ち時間なしで、いつでも再開できる。ドライバーは再開しない（提案の裁定待ちの中断は、これまでどおり GM の裁定後にドライバーが再開する）
- **前提** — 無反応で中断する仕組みそのものがまだ無い（期限 `suspendAt` は表示しているが、期限が来ても中断しない）。この要望で一緒に作る。何日反応が無ければ中断するかは、作るときに決める
- **マイルストーン** — 参加者が別の人になって反応を待つことが起きる M3 に置いた
