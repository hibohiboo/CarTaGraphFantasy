# 結末タグをカードとして持たせる

仕様（[シナリオの構造とセッション開始までの流れ](../cartagraph/scenario-flow.md)）では、結末タグは「既存のカード種別の一種」として PC へ配る。実装は文字列の配列（`Character.endingTags`）で、カードになっていなかった。

2026-09-27、人間の判断で「カードとして持たせる」方針に決まった。キャラクターシートなど複数の画面に関わるため、村スタート冒険者キャンペーンとは別の要望にした。2026-10-14、[シナリオの下書きの API の C2（セッションの独立）](scenario-draft-api.md)で、結末タグをカード（特徴カード）にした。カードは、どのシナリオのどの結末で得たかと再挑戦不可かを、得たときの版の値で持ち、再挑戦不可はこのカードだけで決める。
