# 結末タグをカードとして持たせる

仕様（[シナリオの構造とセッション開始までの流れ](../cartagraph/scenario-flow.md)）では、結末タグは「既存のカード種別の一種」として PC へ配る。実装は文字列の配列（`Character.endingTags`）で、カードになっていない。

2026-09-27、人間の判断で「カードとして持たせる」方針に決まった。キャラクターシートなど複数の画面に関わるため、村スタート冒険者キャンペーンとは別の要望にした。経緯は [既知の問題](../architecture/known-issues.md) の「結末タグの持ち方が…ずれている」。
