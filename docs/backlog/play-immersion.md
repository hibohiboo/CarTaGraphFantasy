# プレイ画面に没入できるようにする

[ロードマップ](../roadmap.md) M2 の完成の条件5に当たる。課題は [画面ごとの課題「プレイページ」](../screens/issues.md#プレイページ) の PLAY-1〜7。

- いまはセッションが始まった後も、アプリのヘッダと「キャラクターシート／セッション一覧／GM の画面へ」のリンクが出続ける
- パーティのキャラクターカードと、プレイマットを出す場所が無い
- 「手札から1枚選んでプレイしよう」「戦闘をはじめよう」の案内が横に並んで邪魔になる
- 戦闘に負けたときの案内文が戦闘のログに重なり、「戦い方を決める」が戦闘の後も出たままになる（既知の問題 [自動戦闘の設定中に、プレイ画面のレイアウトが崩れる](../architecture/known-issues.md#自動戦闘の設定中にプレイ画面のレイアウトが崩れる) と同じところ）
