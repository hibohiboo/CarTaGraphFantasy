# セッションの経験を PC からなかったことにできるようにする

- 2026-10-16、[中核のユースケース](../architecture/use-cases.md)を書いていて、人間が決めた。セッションの結果は、既定で参加したすべての PC に経験として反映する（[PCの貸し借りとフィードバック](../cartagraph/party-and-session.md#pcの貸し借りとフィードバック)）。所有者が「なかったことにする」を選ぶ仕組みは、その要望が実際に出るまで作らない（YAGNI）
- 想定する動機：他人に貸した PC が、所有者の望まない方向に変わるのを防ぐ（それまでの仕様は、所有者が反映するかを選ぶ形だった。[ノート](../notes/party-and-session.md#既定ですべて反映することにした経緯)）
- 作るときに決めること：PC データと [PC 発見グラフ](../cartagraph/graph.md#セッションスナップショットとマージ)を一緒に外すか、別々に選べるか。なかったことにしても、セッションログ（パーティー単位）は残す
