# デザイナーノート：カルタグラフ構想

対応する仕様：[カルタグラフ構想](../cartagraph/index.md)

## 「カルタグラフ・エンジン」という名前の検討

当初、「カルタグラフエンジン」という名称を検討した。検討した案は次のとおり。

- カルタグラフ・エンジン
  - ゲームを動かす内部機構・基盤という印象
- カルタグラフ・コア
  - TRPGの根幹となる考え方・仕組みという印象
- カルタグラフ・システム
  - ルール体系そのものという印象
- カルタグラフ・フレームワーク
  - 他のTRPGにも適用できる基盤という印象

検討の結果は、「カルタグラフ」そのものを概念名とし、必要なら「カルタグラフ・コア」を中核システム名として使う案を推奨。名称はまだ最終決定ではない（未決は[未解決論点](../open-questions.md#仕様の細部の未決)）。
