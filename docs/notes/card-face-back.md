# デザイナーノート：カードの裏表

対応する仕様：[カードの裏表](../cartagraph/card-face-back.md)

## 場のゾーン構造と、種別ごとの運用の経緯

「場のゾーン構造」と「個々のカード種別ごとの裏表の運用」は、どちらも grilling による深掘りで決めた。

## 裏表を2値に限った理由

友好度・生存/死亡のような状態変化を状態タグに分けると、「裏返す」という基本操作の意味を2値のまま保てる。

## 「デザイン上の裏面のみ」の種別

「情報的には常に公開だが見た目上だけ裏面がある」に明確に該当するカード種別は、検討した時点では見つからなかった。具体例が出てきたら仕様に追記する。

## A/Bを固定ルールにしなかった理由

ゾーンで隠すか裏表で隠すかを機械的な固定ルールにせず、カードごとにGM／シナリオ製作者が選べるようにした。「裏表は情報の性質に応じて使い分ける」という設計原則、および[正史グラフの共有設定への格上げ](../cartagraph/graph.md#正史グラフの共有設定への格上げ)で採ったボトムアップな運用方針と一貫させるため。
