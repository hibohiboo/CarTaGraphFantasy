# デザイナーノート：自動戦闘（仮ルール）

対応する仕様：[自動戦闘（仮ルール）](../cartagraph/auto-combat.md)

## 経緯

2026-09-23、「村スタート冒険者キャンペーン」の冒険者試験を GM 不在で遊べるようにするため、仮ルールとして導入した（検討経緯は `docs/plans/2026-09-23-自動戦闘エンジン.md`）。

2026-09-27 から、村スタートのシナリオは「ソロ開始時の初期装備」を使わず、[GM不在のソロの進行（仮ルール）](../cartagraph/solo-village.md)で依頼・お店を通じて HP・＜行動値＞・戦闘スキルを得るようになった。初期装備は、村パートを持たないシナリオ用の仮ルールとして残している（いまはテスト専用のシナリオだけが使う）。

## 将来の拡張候補

- 補助・移動カード、状態異常、射程・空間モデルへの対応
- 複数の敵、自分のHP以外を見る条件（相手のHP、ラウンド数など）
- 1手ずつ再生する演出
- 数値バランスの確定。カウント制では、1ラウンドの行動回数によって「基本攻撃でHPの2〜3割」と「3〜5ラウンドで決着」（[数値バランスの相場観](../cartagraph/balance.md)）を両立できない場合がある。村スタートのシナリオでの勝率・決着ラウンドは[シミュレーション結果](../cartagraph/auto-combat-simulation.md)を参照
