# デザイナーノート：戦闘ルール

対応する仕様：[戦闘ルール](../cartagraph/combat.md)

## 時間と空間を独立させた経緯

grilling による深掘りで、時間の管理（カウント制）と空間の管理（1次元／2次元）は独立した軸として設計すると決めた。

## カウント制の考え方

- マイナスの持ち越しは「無理をした反動で次ラウンドは本来より遅くなる」ことの表現
- コストが高いほど強い、というトレードオフにしたのは、「今すぐ強い一撃を出すか、複数回の素早い行動で手数を稼ぐか」という選択を戦略にするため
- カードを逐次選択にしたのは、この駆け引きが戦闘の楽しさの核だから。[セッション参加モデル](../cartagraph/party-and-session.md#ドライバーとナビゲーター決着)で「ドライバーをパーティー全体で1人」と決めた理由の一つでもある

## 移動をカードにした理由

[カードのプレイ＝世界への操作](../cartagraph/play-and-field.md#カードのプレイ世界への操作)という既存の原則にそのまま乗せるため。

## 射程とグループの考え方

同じグループ内なら誰でも狙えるのは、乱戦中は細かい位置関係を無視し、同じ塊にいる相手なら誰でも狙える、という表現にするため。

Target と統合しなかったのは、射程・グループはプレイ時に PL が動的に選ぶ空間的な仕組みで、Target とは目的が違うため。

## 判定の考え方

回復・補助カードに判定を設けなかったのは、失敗によって回復・補助が不発になる体験の苦しさを避けるため。

## 終了条件と HP0 の考え方

- GM が任意に戦闘を終了できるのは、機械的な自動判定より人間の裁量を優先する、という一貫した方針に沿うため
- HP0 を裏返し・デッキ移動ではなく状態タグで表すのは、状態の可逆性を素直に扱うため
