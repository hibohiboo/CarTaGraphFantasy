# プラン：React化済みの試作HTMLの削除

書式は `docs/process/index.md` の「プランドキュメントの8項目」。小さな整理のため簡潔に書く。

## 1. 概要

`docs/public/preview/` の試作HTML15画面のうち、React化済みの10画面を削除し、それを参照しているサイドバー・サイトマップ・ドキュメントを整える。未React化の5画面は、React化するときの参照元として残す。

## 2. 背景

- 2026-09-27、人間の依頼（「役目を終えたHTMLを消しましょう」）。どこまで消すかは人間が「React化済みの10画面だけ」と決めた
- `AGENTS.md` は `docs/public/preview/` を「役目を終えつつある。参照元として残置」としている。React化済みの画面は参照元としての役目も終えた
- React化済みの判定：`apps/web/src/app/routes.ts` の `prototype` フィールドで試作元として参照されている9画面と、`components/PlayMat.tsx` に移植済みの `play-mat.html`
- 未React化で残す5画面：`combat-play.html`・`combat-play-1d.html`（`docs/architecture/web-app.md`「未React化の画面」で残すと明記）、`session-chat.html`・`scene-play.html`・`session-field.html`（対応するReactの画面が無い）

## 3. 詳細設計

- 削除（10）：`cartagraph-zukan.html`・`session-play.html`・`session-gm-review.html`・`session-gm-manage.html`・`scenario-manage.html`・`session-browse.html`・`character-create.html`・`scene-builder.html`・`character-sheet.html`・`play-mat.html`
- `docs/.vitepress/config.mts`：サイドバー「試作」から削除した10画面の項目を外す（残り5画面は残す）
- `apps/web/src/app/routes.ts`：`RouteMeta.prototype` フィールドと値を削除する。残る試作はどれもルートを持たないため、このフィールドは使われなくなる
- `apps/web/src/pages/admin/SitemapPage.tsx`：「試作元」列と `PREVIEW_BASE` を削除する
- `docs/architecture/web-app.md`「未React化の画面」：サイトマップの `prototype` の説明を消し、「React化したら試作HTMLを削除する（元の試作は git 履歴から参照する）」に置き換える
- `docs/architecture/prototype-handover.md`：画面一覧の表はそのまま残し（PR #6 と同じ行を触らないため）、冒頭と「削除した試作」節で、10画面を削除したことと git 履歴での参照方法を書く
- `AGENTS.md`：`docs/public/preview/` の説明を「未React化の画面の試作だけを残す」に更新する
- コードのコメント（`PlayMat.tsx`・`CreatorSceneEditPage.tsx`）：削除した試作のパスを指しているため、「git 履歴にある」旨に直す
- `packages/domain` の型変更：なし

## 4. テスト影響範囲

- `pages.test.tsx` の全ルート描画（`/admin/sitemap` を含む）：列を1つ減らすだけで、見出しの描画は変わらない
- E2E スモーク：ルートは変えないため影響なし
- `pnpm docs:build`：サイドバーから消した試作へのリンクが残っていないこと（リンク切れ検査）で確認する

## 5. 新規テストケース

振る舞いの追加がないため、新規テストは書かない。既存の全ルート描画・docs ビルドで回帰を確認する。

## 6. 実装順

1. 試作HTMLの削除とサイドバーの更新 → `pnpm docs:build`
2. `routes.ts`・`SitemapPage.tsx` → `pnpm web:typecheck && pnpm web:test`
3. ドキュメント（`web-app.md`・`prototype-handover.md`・`AGENTS.md`）とコードのコメント

いずれも定型作業のため、どのモデルでも可。

## 7. コミット前テスト実行

```sh
pnpm web:typecheck && pnpm web:test && pnpm docs:build
```
